## Key Interactions to Verify

- Open a local, an mmap and a remote file, and read the same columns: identical results (`tests/cases`, every source).
- Write a file in the scope API with several writers on several threads, then open it in ROOT and in uproot (cross-check).
- Update an existing file (append, replace, delete); ROOT opens it, and so does our reader.
- Interrupt an update at every write index; the file shows the old or the new content (D9).
